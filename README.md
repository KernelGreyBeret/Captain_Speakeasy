# Captain_Speakeasy

Official source for **captainspeakeasy.com**.

## Identity

The site uses the Captain_Speakeasy production palette:

| Token | Hex |
|---|---|
| Charcoal | `#0E0F12` |
| Aged Brass | `#C9A34A` |
| Oxblood | `#5B0F1A` |
| Warm Ivory | `#F2E9D8` |
| Cyan Accent | `#22D3EE` |
| Violet Accent | `#8B5CF6` |

Core identity assets live under `assets/`, including the primary crest, round badge,
CS monogram, five section icons, hero banner, brand guide, and animated Captain hero.

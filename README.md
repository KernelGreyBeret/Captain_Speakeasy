## External destinations

External creator destinations are centralized in `script.js` so links stay consistent
across the site.

## Runtime

The site is static HTML/CSS/JavaScript with no build dependency.


## Captain's Workshop

The site includes a dedicated embedded tutorial showcase. The featured tutorial loads
as a muted autoplay preview only after the workshop scrolls into view; the secondary
tutorials use normal embedded YouTube players.

## Platform marks

Local SVG marks are included for Twitch, YouTube, TikTok, Discord, X, Patreon, and
Buy Me a Coffee so the public site does not depend on an icon CDN.

## Rich channel preview cards

The Watch room now uses locally curated visual previews from Eric's supplied banners,
with platform marks and handles. Instagram is a fifth destination.

## Jump the Gun
